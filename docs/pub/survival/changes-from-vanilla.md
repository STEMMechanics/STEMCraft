# Changes from Vanilla

## Iron Golems

Iron Golems drop iron nuggets instead of iron ingots. The bundled defaults produce 3–5 nuggets, although the live server can configure the range.

## Phantoms

Natural insomnia phantoms are blocked in Overworld environments. In End environments, natural Enderman spawns are changed to a random 50/50 mix of Endermen and Phantoms.

## Anvils

The current default keeps Minecraft's repair-cost behavior and warns before the 40-level “Too Expensive” limit. The plugin still contains a configurable no-repair-cost feature, but it is disabled by default.

## Other changes awaiting deployment confirmation

The old handbook described altered villager currencies and cobblestone-to-gravel-to-sand stonecutter recipes. The plugin supports configurable stonecutter recipes, but the bundled version/26.2.x defaults do not establish those old player-facing values. Confirm the live Survival configuration before documenting them as active.
