# Mailboxes

Mailboxes provide delayed player-to-player deliveries. Place a mailbox using its custom recipe, put items inside, and close it to open the recipient and message form. Java uses an in-game dialog and Bedrock uses an equivalent form.

Every delivery includes a written letter naming its sender and containing the message. If the recipient is offline, their notification appears when they return. A personal indicator appears above mailboxes containing delivered mail for them.

Delivery timing and mailbox availability are controlled by the live server.

{% hint style="warning" %}
Double-check the recipient's name before sending valuable items. Ask staff for help if a delivery appears to be missing.
