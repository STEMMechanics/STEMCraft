# Custom Items

Custom items can have their own name, appearance, description, food values, stacking rules, placement behavior, and recipes. The server provides matching Java and Bedrock visuals where configured.

Current documented examples include [Fried Eggs](fried-eggs.md), [Slime and Magma Buckets](slime-and-magma-buckets.md), [Animal Barrels](../animal-barrels.md), mailboxes, and [Gifts](gifts.md). Their ordinary base material does not necessarily describe how the custom item behaves.
