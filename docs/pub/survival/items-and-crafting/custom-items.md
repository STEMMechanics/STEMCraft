# Custom Items

Custom items can have their own name, appearance, description, food values, stacking rules, placement behavior, and recipes. The server provides matching Java and Bedrock visuals where configured.

Current documented collections include all 64 items in [Farming, Foraging & Cooking](farming-and-cooking.md), [Fried Eggs](fried-eggs.md), [Slime and Magma Buckets](slime-and-magma-buckets.md), the items in [Useful Rotten Flesh](rotten-flesh-uses.md), [Animal Barrels](../animal-barrels.md), [Mailboxes](../mailboxes.md), and [Gifts](gifts.md). Their ordinary base material does not necessarily describe how the custom item behaves.
