# Chisel

The Chisel is a building tool that rotates supported blocks without making you break and replace them. It works for both Java and Bedrock players.

## Crafting

Place one **Iron Ingot** directly above one **Stick** in a crafting table. The recipe makes one Chisel.

```text
┌───┬───┬───┐
│   │ I │   │  I = Iron Ingot
├───┼───┼───┤
│   │ S │   │  S = Stick
├───┼───┼───┤
│   │   │   │
└───┴───┴───┘
```

## Using it

Hold the Chisel in your main hand and right-click the block you want to turn. On Bedrock, use the normal place/use control while pointing at the block. A successful turn makes a grindstone sound, shows a few particles, and uses one point of durability.

The Chisel can rotate:

* stairs, while keeping their upside-down or right-way-up state;
* glazed terracotta;
* logs, wood, stems, pillars, hay bales and other blocks with an axis;
* standing signs, banners, heads and other freely rotatable decorations;
* carved pumpkins and jack o'lanterns.

Plain and coloured terracotta do not have a direction in Minecraft, so they cannot be rotated. The Chisel also leaves doors, beds, chests, rails, machinery and redstone blocks alone because turning those could damage a build.

The Chisel has 256 uses. It does not lose durability in Creative mode, and it only wears down when a block actually turns.
