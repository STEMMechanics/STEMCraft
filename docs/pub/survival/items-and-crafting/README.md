# Items & Crafting

STEMCraft can add custom items and recipes while keeping them usable by Java and Bedrock players. Accept the [Resource Pack](../../getting-started.md#accept-the-resource-pack) so these items display correctly.

The exact item and recipe selection comes from the live server's data packs and can change without a plugin code change.

Start with [Useful Rotten Flesh](rotten-flesh-uses.md) to learn how zombie drops can become farming supplies, Dog Treats, Zombie Bait, and a strange stew.

The [Farming, Foraging & Cooking](farming-and-cooking.md) guide lists the complete Cooking collection, where to find its ingredients, and the recipe for every prepared ingredient, meal and drink.
