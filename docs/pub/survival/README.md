# Survival

STEMCraft Survival keeps the familiar Minecraft progression while adding practical community features, custom items, and selected [Changes from Vanilla](changes-from-vanilla.md).

Current plugin-backed features include mailboxes, notice boards, graves, animal barrels, farming and inventory improvements, faster transport and leaf decay, equipment warnings, and automatic End Dragon respawning. Waystones, traders, and survival cities are retained in this handbook as planned features.
