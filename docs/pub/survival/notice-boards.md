# Notice Boards

Click a physical notice board to create and manage a short community notice. A notice has a heading, message, and author.

Each player can have one active notice created through a board. Clicking again lets you edit or delete it. Notices expire automatically after 14 days by default, though the live server can use a different retention period.

Trades and arrangements advertised on a board still happen directly between players.

Keep headings short and messages friendly. Never post private information. Read the [community rules](../safety-and-community/rules.md) before publishing a notice.
