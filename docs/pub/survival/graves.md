# Graves

When a player dies in Survival with items to drop, the plugin tries to store those items in a grave near the death location.

On land, the grave is a buried chest with a sign above it. In water or lava, the plugin tries to build a safe marked storage area at the liquid surface. Large inventories can use a double chest. If no suitable location can be created without damaging the surroundings, items fall normally instead.

After you respawn, chat shows where you died. While your grave remains unopened, the coordinate boss bar also shows a gravestone, its compass direction and distance. If the grave is in another world, it shows that world's name instead—for example, **Nether**—and changes to direction and distance when you enter that world. Active graves also appear on Pl3xMap when the server map is available.

Opening either grave chest or breaking the chest or grave sign removes its coordinate-bar waypoint and map marker. Any player can recover a grave, so the marker also disappears if someone else reaches it first.

Return carefully: the danger that defeated you may still be nearby. If the plugin could not make a grave, look for normal dropped items around the death spot.
