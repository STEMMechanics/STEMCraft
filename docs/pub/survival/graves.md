# Graves

When a player dies in Survival with items to drop, the plugin tries to store those items in a grave near the death location.

On land, the grave is a buried chest with a sign above it. In water or lava, the plugin tries to build a safe marked storage area at the liquid surface. Large inventories can use a double chest. If no suitable location can be created without damaging the surroundings, items fall normally instead.

Return carefully: the danger that defeated you may still be nearby. If the plugin could not make a grave, look for normal dropped items around the death spot.
