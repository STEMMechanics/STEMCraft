# Parkour

## Your goal

Run and jump from the start to the finish as quickly as you can. Your run is timed, so you can practise the same course and try to improve your record.

## Quick tips

- Line up each jump before sprinting.
- Use short movements on small platforms.
- If a restart choice is available, use it for a fresh timed attempt.
- Check the leaderboard to see the times you are chasing.
