# Commands

Available commands depend on the world and your permissions. Common player-facing commands implemented by the plugin include:

| Command | Purpose |
| --- | --- |
| `/hub` | Return to the hub. |
| `/spawn` | Return to an available world spawn. |
| `/back` | Return to your previous stored location when allowed. |
| `/warp <name>` | Travel to an available named warp. |
| `/coord` | Toggle coordinate information. |
| `/coordbar` | Toggle coordinates in the boss bar. |
| `/resourcepack` | Ask the server to resend its Java resource pack. |
| `/report <message>` | Send a player report to staff. |

Minigames can provide their own join or leave commands. Use in-game menus and command suggestions to see what is enabled.

Administrator, moderation, world-management, and developer commands are intentionally omitted from this player handbook.
