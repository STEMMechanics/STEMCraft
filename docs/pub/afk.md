# Going AFK

AFK means “away from keyboard”. After five minutes without activity, STEMCraft marks you AFK, italicises your name in the tab list, and sends a yellow message such as **James is now AFK**. Returning sends **James is no longer AFK**.

Use `/afk` to toggle your status manually. Movement, looking around, chatting, ordinary commands and interactions return you to active status. AFK is not protection: mobs, falling and other world hazards can still affect you. Find a safe place before stepping away.

By default the server kicks you after **30 minutes spent AFK**—35 minutes total inactivity if you let the automatic timer mark you away. These timers can be configured by staff. Reconnect when you are ready to play again.
