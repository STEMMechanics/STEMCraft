# Java & Bedrock

Both editions can play on STEMCraft. Java receives the generated Java resource pack; Bedrock receives a generated pack through the server's Bedrock compatibility layer.

Some presentation can differ between editions. Menus that use Java dialogs are presented as Bedrock forms, while important gameplay actions share the same server-side behavior.

{% hint style="info" %}
The exact supported Minecraft versions are controlled by the live server and can change independently of this handbook. If you cannot connect, ask in Discord.
{% endhint %}
