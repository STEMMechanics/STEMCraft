Add a server with the address **play.stemcraft.com.au** and port **19132**.

<figure><img src="../.gitbook/assets/bedrock-connect.jpeg" alt="Bedrock Edition server settings"><figcaption><p>Bedrock Edition connection settings</p></figcaption></figure>

Use a licensed Minecraft account. If the server requests a simple maths answer on first join, answer it in chat; this is an anti-bot check, not an invitation system.
