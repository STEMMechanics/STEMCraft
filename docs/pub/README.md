# Welcome

<figure><img src=".gitbook/assets/lobby.png" alt=""><figcaption></figcaption></figure>

STEMCraft is a **community driven** Minecraft server created and managed by [STEMMechanics](https://www.stemmechanics.com.au/).

The server contains various game modes such as SkyBlock, BedWars, Bridge, Creative and of course Survival.

This wiki contains all the details you need for your STEMCraft playing experiance as well as information for moderators and workshop participants to help you on your adventures or expand the game with customized items.

Anyone can join the server and play, however follow the server's [rules](master/rules.md). That way everyone can have a fun and safe game.

## Who can join the server?

STEMCraft is a private, invite-only server. To receive an invite, you are required to attend one of our [STEMMechanics](https://www.stemmechanics.com.au/) Minecraft workshops.

If you have received an invite code, follow these steps to register:

1. Join the minecraft server from your client. You will be kicked, however this will verify your player name.
2. Visit [http://play.stemcraft.com.au/invite](http://play.stemcraft.com.au/invite) and enter your invite code and player name.
3. If your player name and invite code is valid, you can now join the server.

Players are also reminded that they need to follow the server's [rules](master/rules.md). That way everyone can have a fun and safe game. You can view the current player punishments at [http://play.stemcraft.com.au/punishments](http://play.stemcraft.com.au/punishments)&#x20;

## How can I join the server?

The server address is: **play.stemcraft.com.au**\
Bedrock port: **19132**\

The server supports the latest version of Java and Bedrock Minecraft. You will require a Mojang/Microsoft account to play.

## What does community driven mean?

By community driven, we mean that over time, the server, game modes, and design change based on the community. This is done through:

* [STEMMechanics](https://app.gitbook.com/o/-MRtgK5mhOMYf2yLJcFv/s/-MGv6HeosnWKnJ4irjJw/) workshops
* Community voting on [Discord](https://discord.gg/yNzk4x7mpD)
* Modifying the [STEMCraft plugin on GitHub](https://github.com/stemmechanics/stemcraft).

STEMMechanics workshops are held both online and in-person. Visit the [STEMMechanics](https://www.stemmechanics.com.au/) website for upcoming events.

## Are there any differences in using Java or Bedrock?

Due to the limitations of Bedrock clients, some of the visual modifications cannot be seen. This includes:

* Biome colour changes (will appear as a single colour)
* Invisible item frames (you will see item frames behind some items)

## Is there a player map?

The server does have a [live map](https://map.stemcraft.com.au/) that shows most of the worlds and players. Note that we purposely do not show live PvP maps and players in the Survival world.

## Where can I get help?

Help for joining, playing or if you want to have a workshop on the STEMCraft server, you can contact us over on our [Discord](https://discord.gg/yNzk4x7mpD) server, or STEMMechanics directly at [hello@stemmechanics.com.au](mailto:hello@stemmechanics.com.au)
