# Events

## Survival Spawn

To get the permission required, talk to one of the STEMCraft crew in [Discord](https://discord.gg/yNzk4x7mpD) or email [hello@stemmechanics.com.au](mailto:hello@stemmechanics.com.au).

## AfterDark

<figure><img src=".gitbook/assets/SC-After-Dark-Discord.png" alt=""><figcaption></figcaption></figure>

The AfterDark event is a survival get-together where players from around the server work together on a single task such as city building or taking down foes. The event is typically run on Wednesday from 7pm.
