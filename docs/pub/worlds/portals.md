# Exploration portals

These are built Survival portals, separate from the Hub's travel portals. Follow the server's current frame diagram and activation instructions: the frame materials, charge and activation items matter.

| Realm | Bundled activation theme |
| --- | --- |
| Wasteland | A reactor-style structure |
| Skylands | A purpur ring charged using Celestial Eyes |
| The Deep | A reinforced-deepslate frame activated with an Echo Core |
| Faraway Lands | A corrupted frame |

Ask STEMBot or staff for the current construction guide before spending rare materials. The Deep's reinforced deepslate and Echo Core are craftable custom recipes. Do not assume a vanilla Nether frame works for these realms.

## Where does the other end appear?

New links use an 8:1 coordinate scale by default and search a limited area for a suitable exit. Existing linked portals keep their paired destination. Both ends can be used by other players.

Skylands' exit can float, but it needs verified terrain or water beneath the arrival area. It does not create an island over the void. If there is no suitable landing nearby, the trip fails and you remain at the entrance. Try another entrance location; an administrator can inspect blocked or broken links.

Step fully off the arrival pad before trying to return. There is a short cooldown to stop you bouncing between portals. Breaking a portal can break its link, even if its counterpart is still physically present. Keep your return route intact and note its coordinates.

## Portal crafting materials

The bundled recipes make four reinforced deepslate blocks from `DID / IAI / DID` (D: deepslate bricks, I: iron ingot, A: amethyst shard). An Echo Core uses `AEA / EDE / AEA` (A: amethyst shard, E: echo shard, D: diamond). Four Celestial Eyes use `AEA / PNP / AEA` (A: amethyst shard, E: ender eye, P: purpur block, N: nether star). Each slash separates a crafting-table row.

These special activation items are not interchangeable with ordinary echo shards or ender eyes. Keep the item names visible when checking a recipe.
