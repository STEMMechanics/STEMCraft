SETUP
Use a Survival test overworld with Citizens and STEMBot enabled. Merge the
new actions, regions and help-topics from the bundled stembot.yml into your
deployed file; preserve its other settings. Set this test region's bounds:

  regions:
    survival-old-terrain:
      bounds: "0,0;7999,7999"
      align-to-chunks: true

Keep its messages. The survival-wilderness action must start with:
  require-world:survival* normal -> survival-wilderness-world-required
  exit-region:survival-old-terrain

Adjust survival* if your test world's name differs. Reload STEMCraft.
Choose safe ground Y values for the X/Z positions below. Use test worlds;
these sample bounds must not replace the real Survival boundary.
