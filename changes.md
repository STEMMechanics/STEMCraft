# Release Notes

Update this file before cutting a release. The release workflow will use this
file as the GitHub release notes when it is present and non-empty.

## Example

- Fix resource-pack metadata handling for Paper 26.x builds.
- Support Paper 26.x integrated dimension storage in the world service.
- Correct GitHub Actions workflow setup for Java 25 builds.

## Notes

- Keep this file concise and user-facing.
- Remove the example items and replace them with the real release summary.
- If this file is blank or missing, the release workflow falls back to the
  associated PR title when GitHub can resolve one, then to the commit subject.
